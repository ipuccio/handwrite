# Installing Handwrite

Handwrite can be used either as a command-line tool or as a web application.

## System Dependencies

Both the CLI and web app require:

1. Install [fontforge](https://fontforge.org/en-US/)

2. Install [Potrace](http://potrace.sourceforge.net/)

## Installation Options

### For Command-Line Usage

Install handwrite via pip:

```console
pip install handwrite
```

### For Web Application

Clone the repository and install dependencies:

```console
git clone https://github.com/builtree/handwrite
cd handwrite
pip install -r requirements.txt
```

See the [Deployment](deployment.md) guide for production deployment instructions.
